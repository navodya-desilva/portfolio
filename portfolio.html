Java Swing Apache NetBeans MySQL Database JDBC Connection
Project Overview

A full-fledged desktop application designed to streamline daily cafe business operations. It automates order taking, invoice billing generation, menu category management, and inventory tracking with persistent data stored in a relational MySQL database.

Key Features & Technical Highlights

  • Database Relational Schema: Built normalized MySQL tables for items, sales transactions, and staff access.
  • OOP Architecture: Developed modular Java classes adhering to Object-Oriented Software Design patterns.
Smart Dustbin (IoT System)
Arduino UNO C++ Microcontroller Ultrasonic Sensor HC-SR04 Servo Motor SG90
Project Overview

An automated touchless waste management prototype built for hygienic trash disposal. Utilizing an ultrasonic distance sensor, the system detects approaching users and automatically triggers a servo motor to open and close the lid smoothly.

Hardware Circuit & System Logic
  • Distance Detection: Measures distance in real-time using ultrasonic pulse wave calculations.
  • Servo Lid Control: Rotates servo motor to 90 degrees when an object comes within 20cm, holding for 3 seconds before closure.
  • Power Efficiency: Optimized loop logic to minimize battery consumption when idle.
